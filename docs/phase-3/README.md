# BB_FME Bevy 이전: 3단계 물리 엔진 기준선

작성일: 2026-08-15  
상태: 완료  
대상: Bevy 0.19 + Avian2D 0.7

## 1. 최종 선택

BB_FME Bevy판의 2D 물리 백엔드로 Avian2D 0.7을 채택한다.

플레이어 공은 Avian2D의 Dynamic RigidBody와 Collider를 사용하지만,
바운스와 벽 반동은 물리 엔진의 반발 계수에 맡기지 않고
BB_FME 게임 규칙으로 직접 계산한다.

기준 구성:

- Bevy 0.19
- Avian2D 0.7
- 물리 주기 50Hz
- Dynamic 플레이어 공
- 원형 Collider
- 질량 5.0
- 중력 배율 3.0
- 회전 잠금
- 마찰 0
- 반발 계수 0
- Transform 보간
- Speculative Collision
- Swept CCD

## 2. 플레이어 Collider 기준

블록 한 칸 크기: 1.0
공 Collider 반지름: 0.2
일반 블록 Collider: 1.0 × 1.0

플레이어 공에는 다음 물리 기능을 적용한다.

RigidBody::Dynamic
Collider::circle(0.2)
Mass(5.0)
GravityScale(3.0)
LockedAxes::ROTATION_LOCKED
Friction::ZERO
Restitution::ZERO
SweptCcd
TransformInterpolation

## 3. 접촉 분류 기준

접촉 법선을 현재 중력 방향을 기준으로 분류한다.

바닥 판정 임계값: 0.7
천장 판정 임계값: 0.7
벽 판정 임계값: 0.9

접촉 처리 우선순위:
바닥
→ 천장
→ 벽

같은 물리 틱에 바닥과 벽 접촉이 함께 발견되면
바닥 반응을 우선한다.

## 4. 바닥 반동

일반 블록의 바닥 면에 닿으면 중력 반대 방향 속도를
최소 9.5로 보장한다.

최소 바운스 속도: 9.5

정확히 9.5로 덮어쓰는 것이 아니라 최소값을 보장한다.
예:
현재 바운스 방향 속도 -7.0 → 9.5
현재 바운스 방향 속도 4.0 → 9.5
현재 바운스 방향 속도 14.0 → 14.0 유지

이 규칙으로 일반 블록에서는 에너지 손실 없이
일정한 높이의 바운스를 반복한다.

## 5. 천장 접촉

공이 천장 방향으로 이동하다 일반 블록의 천장 면에 닿으면
천장 방향 속도 성분을 0으로 만든다.
수평 속도는 보존하며 천장에서 반대로 튕기지는 않는다.

## 6. 벽 반동

벽 반동 속력은 Solver가 입사 속도를 제거하기 전에 저장한
수평 접근 속도를 기준으로 계산한다.

벽 반동 속력
= max(12.0, 입사 속력 × 0.8)

기준값:
최소 벽 반동 속력: 12.0
고속 벽 반동 감쇠 비율: 0.8

예:
입사 속력 5 → 반대 방향 12
입사 속력 12 → 반대 방향 12
입사 속력 20 → 반대 방향 16
입사 속력 30 → 반대 방향 24

공이 벽을 평행하게 스치는 경우와 이미 벽에서 멀어지는 경우에는
벽 반동을 적용하지 않는다.
벽 접근 속도가 0.01 이하라면 수치 오차 또는 스치기 접촉으로 취급한다.

## 7. 검증 결과

7.1 장기 바운스
50Hz에서 10분 동안 총 30,000틱을 실행했다.
결과:
바운스 횟수: 909
바운스 속도 범위: 9.5000..9.5000
공 중심 Y 범위: 0.7000..2.2175
수평 드리프트: 0.000000

확인 사항:

- 바운스가 중간에 멈추지 않음
- 바운스 속도 감소 없음
- 비정상적인 에너지 증가 없음
- 수평 드리프트 없음
- NaN 또는 무한대 없음

    7.2 벽 접촉
    다음을 자동 테스트로 검증했다.

- 오른쪽 벽 저속 충돌 시 최소 속력 12로 반동
- 왼쪽 벽 고속 충돌 시 입사 속력의 0.8배로 반동
- 벽을 평행하게 스칠 때 반동하지 않음
- 벽에서 멀어지는 중에는 반동하지 않음
- 바닥과 벽이 동시에 감지되면 바닥 반응을 우선함

    7.3 Swept CCD
    Speculative Collision의 기본 예측 거리를 테스트에서 0으로 설정하고,
    Swept CCD만으로 극고속 얇은 지형 관통을 막는지 검증했다.

테스트 조건:
물리 주기: 50Hz
공 속력: 200
한 물리 틱 이동 거리: 4.0
얇은 벽 두께: 0.05
얇은 바닥 두께: 0.05

벽 결과:
반동 발생 틱: 2
최대 X 위치: 5.7884
접촉 X 위치: 5.7884
반동 속도: -160.0000

바닥 결과:
반동 발생 틱: 2
최저 Y 위치: 2.2116
접촉 Y 위치: 2.2116
반동 속도: 9.5000

지속 중인 극고속 이동에서 얇은 벽과 바닥을 관통하지 않았으며,
접촉 후 BB_FME의 사용자 정의 반동 규칙이 정상적으로 적용됐다.

## 8. 알려진 제한

8.1 첫 틱 극고속 전환
공의 속도를 정지 상태에서 극단적인 속도 200으로 바꾸고,
같은 첫 물리 틱에 멀리 떨어진 얇은 장애물을 통과시키면
Broad Phase의 이동 경로 정보가 아직 준비되지 않아 관통할 수 있다.

지속 중인 고속 이동에서는 다음 틱용 이동 경로가 준비되므로
Swept CCD가 관통을 방지했다.

따라서 대시, 직진, 대포, 포탈 등에서 속도가 갑자기 변경될 때는
각 기능의 실제 최대 속도로 별도 테스트해야 한다.

필요한 경우 다음 대안을 검토한다.

- 실제 최대 속도 제한
- 고속 상태 진입 전 이동 경로 갱신
- 능력 발동 틱의 Shape Cast
- 포탈 직후 별도 관통 검사
- 사용자 정의 공 컨트롤러

    8.2 아직 검증하지 않은 조합
    다음 항목은 이후 단계에서 별도로 검증한다.

- 실제 좌우 입력과 벽 반동의 조합
- 중력 반전
- 이동 블록
- 곡선 및 부분 블록
- 포탈 직후 고속 이동
- 대시와 직진 아이템
- 스윙
- 복제공
- 동적 장애물과의 충돌
- 모바일 성능

## 9. 결정

3단계 물리 엔진 검증 결과,
BB_FME Bevy판의 물리 기준선으로 다음 조합을 채택한다.

Avian2D 0.7

- 50Hz 물리 주기
- Dynamic RigidBody
- Speculative Collision
- Swept CCD
- BB_FME 사용자 정의 접촉 분류와 반동 규칙

게임 규칙은 Avian2D의 자동 반발력보다
BB_FME가 소유하는 시스템에서 명시적으로 처리한다.

물리 엔진 타입이 블록과 게임 규칙 전체로 퍼지지 않도록
접촉 수집, 접촉 분류, 반동 규칙과 이동 규칙을 계속 분리한다.
